## About the Project

Functional-Treat is a simple Python console-based program used to
enter, analyze, filter, and sort a one-dimensional list of numbers.

The program uses a menu-driven system so that users can select
different operations according to their requirements.

## Features

The project provides the following options:

1. Input Data
2. Display Data Summary
3. Calculate Factorial
4. Filter Data by Threshold
5. Sort Data
6. Display Dataset Statistics
7. Exit Program

## Program Operations

### 1. Input Data

The user can enter multiple numbers separated by commas.
The entered values are converted into a list of integers and stored
for further operations.

### 2. Display Data Summary

This option displays the total number of elements, minimum value,
maximum value, sum of all values, and average value.

### 3. Calculate Factorial

This option accepts an integer from the user and calculates its
factorial using a recursive function.

### 4. Filter Data by Threshold

The user enters a threshold value.
The program displays the values that are greater than or equal to
the entered threshold.

### 5. Sort Data

The program allows the user to sort the stored data in:

- Ascending order
- Descending order

### 6. Display Dataset Statistics

This option displays statistical information such as the minimum,
maximum, sum, and average of the stored dataset.

### 7. Exit Program

This option closes the program and displays a goodbye message.
